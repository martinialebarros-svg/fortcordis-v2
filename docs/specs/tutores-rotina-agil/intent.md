# Intent — tutores-rotina-agil

Data: 2026-10-27
Responsavel: Martiniano + Codex

As clinicas frequentemente informam somente o primeiro nome do tutor e o nome do
pet. Agendar deve continuar rapido; o veterinario complementa os dados durante
o atendimento. A pendencia deve ser visivel sem criar etapa obrigatoria,
pop-up ou consulta de duplicidades no caminho do agendamento.

A evolucao combina selecao explicita de pessoas existentes, fila de pendencias,
confirmacao de identidade com evidencia, repeticao segura de solicitacoes,
contatos/origens alternativos e correcao conservadora de mesclagens equivocadas.
